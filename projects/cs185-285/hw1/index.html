Homework 1 · Imitation Learning

Action Chunking with MSE and Flow Matching

I trained visuomotor policies for Push-T, compared a direct MSE action-chunk predictor with a conditional flow-matching policy, and then tested how the learned behavior changed under uneven friction.

  • Behavior Cloning
  • Flow Matching
  • Visuomotor Control
  • Robustness
Assignment ↗ Report ↗ Code ↗

Overview

Learning multimodal actions from demonstrations

Push-T requires a policy to infer a useful contact point and produce a coordinated sequence of actions from image observations. I used the same three-layer, 256-hidden-dimension MLP backbone for both policies so that the learning objective—not model scale—drove the comparison.

The MSE model predicts an action chunk directly. The flow-matching model instead learns a conditional vector field that iteratively moves noise toward the demonstrated action distribution, making it better suited to multiple valid behaviors.

Implementation

What I built

  • An MSE behavior-cloning baseline that predicts a full action chunk.
  • A conditional flow-matching policy with iterative action refinement.
  • Checkpoint evaluation tools and rollout logging for direct comparison.
  • Uneven-friction Push-T variants that stress different regions of the T-shaped object and workspace.

Results

Flow matching produced stronger, more decisive behavior

At 70,000 training steps, the flow policy achieved the higher evaluation reward. Qualitatively, its rollouts selected more effective contacts and pushed with fewer back-and-forth corrections near the target. The uneven-friction experiments provided a further robustness check beyond the standard environment.

≈ 0.802 Flow-matching evaluation reward at 70k steps
≈ 0.576 MSE action-chunk evaluation reward at 70k steps
