Homework 4 · LLM Reinforcement Learning

REINFORCE and GRPO for Language Models

I implemented sequence-level reinforcement learning for Qwen2.5-Math-1.5B and compared REINFORCE with GRPO on controlled format copying and harder mathematical reasoning tasks.

  • LLM RL
  • REINFORCE
  • GRPO
  • Mathematical Reasoning
Assignment ↗ Report → Code ↗

Overview

Policy gradients at the token-sequence level

This project adapted policy-gradient ideas to autoregressive language generation. I computed response log probabilities, constructed rollout buffers, and implemented both a standard REINFORCE objective and the group-relative advantage calculation used by GRPO.

Experiments

Format control and mathematical reasoning

  • A format-copy task for validating reward-driven sequence learning.
  • REINFORCE and GRPO under matched model and task settings.
  • KL regularization and grouped rollouts during policy updates.
  • Evaluation on Math Hard using boxed-answer exact match.

Results

Group-relative advantages improved the final score

Both methods learned the constrained output format, but GRPO produced the stronger final Math Hard result. Comparing the two made the value of within-prompt grouped samples concrete: they supplied a useful relative learning signal without a separate learned critic.

37.70% Final boxed exact match with GRPO
28.32% Final boxed exact match with REINFORCE
