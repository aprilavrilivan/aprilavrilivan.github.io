Homework 5 · Offline Reinforcement Learning

SAC+BC, IQL, and Flow Q-Learning

I implemented three offline RL approaches and compared how they balance value improvement against staying close to a fixed behavior dataset on robotic manipulation and long-horizon navigation tasks.

  • Offline RL
  • SAC+BC
  • Implicit Q-Learning
  • Flow Q-Learning
Assignment ↗ Report → Code ↗

Overview

Policy improvement without new environment interaction

Offline RL has to improve a policy using only logged data, which makes out-of-distribution actions especially dangerous. I compared three strategies for controlling that risk: explicit behavior-cloning regularization, expectile-based implicit value learning, and a flow-based policy objective.

I evaluated every method on Cube Single, a manipulation task, and AntSoccer Arena, a more difficult navigation task. For each one, I swept the behavior-cloning coefficient to see where policy improvement gave way to either extrapolation error or excessive conservatism.

Methods

Three ways to stay close to the data

  • SAC+BC: combines an actor-critic objective with an explicit behavior-cloning penalty.
  • IQL: uses expectile value regression and advantage-weighted behavior cloning without querying unseen actions in its value target.
  • FQL: learns a flow policy and uses Q-values to guide it toward higher-return actions while retaining behavioral support.

Results

Moderate regularization was consistently strongest

SAC+BC achieved strong peaks when its coefficient was tuned carefully, while IQL was generally less sensitive across the tested values. FQL delivered the strongest selected AntSoccer result, but its performance also showed why offline policy constraints need careful calibration: too little regularization caused out-of-distribution errors, while too much prevented useful improvement.
