Homework 3 · Value-Based & Actor-Critic RL

Deep Q-Learning and Soft Actor-Critic

I implemented DQN and Double DQN for discrete action spaces, then built a Soft Actor-Critic agent for continuous control and examined target updates, entropy tuning, and Q-value overestimation.

  • DQN
  • Double DQN
  • Soft Actor-Critic
  • Entropy Tuning
Assignment ↗ Report → Code ↗

Overview

Two families of off-policy learning

The first half of the project focused on stabilizing temporal-difference learning with replay buffers, target networks, and Double DQN. The second half moved to continuous actions with SAC, combining stochastic policies, twin critics, and entropy regularization.

Implementation

What I built and compared

  • DQN training with replay, target networks, and exploration schedules.
  • Double DQN targets to reduce maximization bias.
  • SAC actor and critic updates for continuous-control environments.
  • Automatic entropy-temperature tuning.
  • Single-Q and clipped double-Q backups on Hopper.

Results

Clipped double-Q sharply reduced the failure mode

The clearest ablation appeared on Hopper. The single-Q variant was substantially weaker, while the clipped double-Q backup produced a much stronger policy. The full experiment suite also covered CartPole, LunarLander, Ms. Pac-Man, HalfCheetah, and InvertedPendulum.
